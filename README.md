# 🌐 Apiurl - Consumo de APIs en Java

Un proyecto desarrollado en **Java** dentro de **NetBeans IDE** diseñado para realizar peticiones a URLs de servicios API, procesar respuestas y gestionarlas mediante una interfaz gráfica.

---

## 🚀 Características
- **Peticiones HTTP:** Conexión y consulta a endpoints/URLs mediante protocolos estándar.
- **Interfaz Gráfica:** Módulo `interfaz.Interfaz` diseñado para interactuar con el usuario.
- **Procesamiento de Datos:** Recepción y manipulación de respuestas provenientes de APIs.
- **Manejo de Errores:** Control de excepciones de red y gestión de respuestas HTTP.

---

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** Java (JDK 17+)
- **IDE:** NetBeans IDE
- **Control de Versiones:** Git & GitHub
